# Multimodal-Augmented Structural Reasoning: Training-Free Multimodal Knowledge Graph Completion

**[English]** | [[中文说明]](#chinese-readme)

This repository contains the official implementation code for the paper **"Multimodal-Augmented Structural Reasoning: Training-Free Multimodal Knowledge Graph Completion"**.

We propose a universal Knowledge Graph (KG) reasoning framework that integrates Multimodal Large Language Models (LLMs). It supports various LLM suites (OpenAI GPT series, Qwen/QwQ series) and benchmarks on mainstream datasets (WN18RR, FB15k-237).

## 🌟 Core Features
- **Multimodal Augmentation**: Enhances entity semantics by fusing visual features with textual descriptions generated by Visual LLMs (GPT-4o-mini / Qwen-VL).
- **Adaptive Structural Search**: Implements dynamic 2-hop/3-hop BFS search combined with SBERT semantic re-ranking to retrieve optimal path evidence.
- **Diverse Sampling**: Utilizes a Round-Robin relation sampling algorithm to ensure high relational diversity within the context window.
- **Decoupled Design**: A unified codebase supporting SOTA experiments, baseline comparisons, and full ablation studies.
- **Multi-Model Support**: Natively compatible with OpenAI API format, supporting GPT-4o and reasoning-enhanced models like QwQ (Chain-of-Thought).

## 🚀 Running Experiments
All steps are managed via `main.py`.

### Step 1: Preprocessing (Multimodal Description Generation)
Generate visually augmented descriptions (Run only once):
```bash
# Example for WN18RR
python main.py --dataset wn18rr --mode openai_suite --step 1
```

### Step 2: Main Experiments (SOTA)
```bash
# Run WN18RR with GPT-4o
python main.py --dataset wn18rr --mode openai_suite --step 2 --ablation full_model

# Run FB15k-237 with QwQ
python main.py --dataset fb15k237 --mode qwen_suite --step 2 --ablation full_model
```

### Step 3: Ablation Studies
Reproduce ablation results by modifying the `--ablation` argument:

```bash
# Remove Visual Information
python main.py --dataset wn18rr --mode openai_suite --step 2 --ablation no_visual

# Remove Path Evidence
python main.py --dataset wn18rr --mode openai_suite --step 2 --ablation no_paths

# Remove Chain-of-Thought (CoT)
python main.py --dataset wn18rr --mode openai_suite --step 2 --ablation no_cot
```

### Step 4: Evaluation
Calculate Hits@1, Hits@3, Hits@10, and MRR:
```bash
python main.py --dataset wn18rr --mode openai_suite --step 3 --ablation full_model
```

## 📊 Ablation Settings
Switches are defined in `DEFAULT_ABLATION` within `config/config.py`:

| Switch Name | Function | Effect when Ablated |
| :--- | :--- | :--- |
| `use_visual` | Visual Augmentation | Uses text-only definitions; truncates `[Visual]:` content. |
| `use_paths` | Path Search | Removes multi-hop structural path evidence from the prompt. |
| `use_neighbors` | Neighbor Sampling | Removes 1-hop diverse neighbor context. |
| `use_cot` | Chain-of-Thought | Forces direct output without the reasoning process. |
| `use_candidates` | Relation Constraints | Removes the candidate list (Zero-shot prediction). |
